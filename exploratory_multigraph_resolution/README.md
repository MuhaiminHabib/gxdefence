# Transaction identity versus model resolution

Separate exploratory, retrospective audit motivated by Crabbé and van der Schaar (NeurIPS 2023), https://arxiv.org/abs/2304.06715, and Xu et al. (July 2026 preprint), https://arxiv.org/abs/2607.26344. Symmetry-aware explanations and reporting are existing ideas. Our candidate contribution concerns their effect on adversarial explanation evaluation in directed financial transaction multigraphs; no first-ever symmetry or metric claim is made.

The fixed GraphSAGE consumes node features and directed edge endpoints, with no per-edge amount, time or transaction ID. Conditional on fixed node features, parallel rows with identical ordered endpoints produce identical messages. Keeping the same selected multiplicity at every ordered pair leaves the retained and removed graph's endpoint multiset unchanged. Induction over message-passing layers gives identical predictions in exact arithmetic. Transaction identities need not be economically equivalent; recomputing amount/time aggregates after changing record identity can break this equivalence. This audit does not modify, collapse or retrain the graph.

We already inspected the saved 50-target-per-dataset fresh-seed audit before writing this script. All analyses here are exploratory. Sources, exact masks and parameters are hashed. Extend the descriptive analysis to the completed three-trial GNN-targeted cohort without new attack optimization, and use completed native SubgraphX results on AMLSim as a structural control. Never read an incomplete HI-Small run into the cohort.

Compare original row-ID cosine with the maximum overlap obtainable by matching rows within each ordered endpoint pair. For the GNN analysis, only original rows available in BOTH explanation input pools may be matched; new, deleted or inaccessible edges are not repaired by matching. The denominator remains sqrt(original selected cardinalities product). Report top-25% and fixed top-10 separately. This quantity is an upper bound under the stated representation equivalence, not a corrected attack-success rate. Its increase is nonnegative by construction and is not by itself evidence of better explanation quality or a novel statistical effect. For native SubgraphX, use an even more permissive endpoint-count bound over selected sets; whole induced groups should show no within-pair identity substitution gap.

Mechanical validation: for each of the 100 saved audit targets and five fresh clean explanations, construct another set of the SAME size and SAME selected multiplicities at every ordered pair, choosing different existing row IDs wherever possible. Evaluate both physical removal and retention with the frozen classifier/features and verify target logits match (atol=3e-5, rtol=3e-5). These constructed sets are equivalence controls, not new explainer outputs or attacks on transactions. Include an equal-cardinality unrestricted random set as a numerical sensitivity reference. Preserve original and alternative IDs and all logits. Use one CPU thread; do not add GPU or SubgraphX search load.

Average seeds/trials within target before 5,000 target-bootstrap resamples. Intervals quantify descriptive cohort variation, not graph dependence or training uncertainty. The larger saved cohort overlaps the initial screening cohort and is not independent confirmation. The result remains conditional on this edge-attribute-blind architecture and fixed feature matrix.

Related boundary: financial multigraph structural attacks already exist (Heijmans et al., accepted LoG 2026), https://arxiv.org/abs/2610.31718. A generic claim to introduce multigraph attacks would be inappropriate.

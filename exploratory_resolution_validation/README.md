# Prospective fresh-randomness validation of multigraph explanation resolution

Separate exploratory extension authorized by the user. Fifty targets per dataset are sampled independently of attack outcomes, excluding the original 50-target fresh-seed cohort. All source targets were included in the earlier retrospective aggregate audit, so this is new explanation randomness and a disjoint fresh-audit cohort, not a wholly unseen-data replication. The model and dataset remain fixed.

Replay source trial 2026 GNN-targeted, best-of-40 random-search and random-flipping attacks. Run five unseen paired clean/attacked seeds 110001--110005, independent clean-repeat seeds 111001--111005, and a deterministic edge-column permutation of the clean graph for each seed. Map permuted explanations back to original transaction IDs. Verify unchanged predictions under permutation. The latter is an actual explainer rerun, unlike the earlier constructed equivalent-mask control. Random initialization is assigned by column position, so this measures implementation-level ordering sensitivity, not a pure tie-breaking theorem.

Use top-25% and top-10 original-row overlap and the original audit's common-pool within-endpoint matching diagnostic. Primary endpoint: the target-level difference between matched and row-based clean-repeat-minus-attack similarity for GNN-targeted attacks at top-25%. Average five seeds within targets; 5,000 target-bootstrap draws. The independent clean repeat is a variability reference, not a perfectly matched null for same-seed clean/attacked comparisons. Matching necessarily increases overlap; a larger overlap alone is not evidence of better explanation quality. Native permutation outputs and fidelity provide additional checks.

Validate source-mask parity, original full-graph/local predictions and fidelity on one target per dataset, then launch the fixed 100-target cohort. Check source/checkpoint hashes on resume, freeze classifier weights, checkpoint each target, one CPU thread and at most 20% GPU allocator memory per process. All artifacts stay here. No modification of any existing study or running source files.

Related work already studies symmetry: https://arxiv.org/abs/2304.06715 and https://arxiv.org/abs/2607.26344. The candidate contribution concerns financial multigraph attack evaluation under this fixed-feature, edge-attribute-blind model.
